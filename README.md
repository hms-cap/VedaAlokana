# VedaAlokana — Vedālokana

A web app for browsing the four Veda Saṃhitās by structure (maṇḍala, kāṇḍa, adhyāya, sūkta), **ṛṣi**, **devatā** and **chandas**, built only from openly published data. Filters combine, so you can ask for every ṛk to Agni in Gāyatrī by Medhātithi Kāṇva, then read each sūkta with svara-marked Devanagari, IAST, Padapāṭha and a translation.

It is a static site: plain HTML, CSS and JavaScript with pre-built JSON, no framework and no server.

## Run it locally

```sh
cd web
python3 -m http.server 8000
# open http://localhost:8000
```

## What's in each Saṃhitā

| Saṃhitā | Text | Ṛṣi / devatā / chandas |
|---|---|---|
| Ṛgveda, Śākala | 10,552 ṛks: Devanagari with svaras, IAST, Padapāṭha, Griffith's English | Per ṛk, from the digitised Sarvānukramaṇī |
| Atharvaveda, Śaunaka | 6,128 mantras: Devanagari with svaras, IAST | Per sūkta, parsed from the Anukramaṇī header of each sūkta (kāṇḍa 20 has none) |
| Śukla Yajurveda, Vājasaneyi Mādhyandina | 1,966 mantras in 40 adhyāyas: Devanagari with svaras, IAST | Not available yet |
| Sāmaveda, Kauthuma | 1,794 verses, Griffith's English only | Devatā from Griffith's hymn headings |

Details, licences and known gaps: [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md).

## Rebuild the data

The JSON in `web/data` is generated by `scripts/build-data.mjs` (Node 18+, no dependencies) from three public repositories:

```sh
git clone --depth 1 https://github.com/031323/vedaweb-data
git clone --depth 1 https://github.com/mahesh-ak/WSC2023
git clone --depth 1 https://github.com/bhavykhatri/DharmicData

node scripts/build-data.mjs \
  --vedaweb vedaweb-data \
  --anukramani WSC2023/Anukramani \
  --dharmic DharmicData \
  --out web/data
```

## Layout

```
web/            the app (index.html, app.js, styles.css) and its data/
scripts/        data pipeline and a small Devanagari ⇄ IAST transliterator
docs/           data sources, licences, gaps
```
