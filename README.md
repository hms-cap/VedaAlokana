# VedaAlokana — Vedālokana

A web app for browsing the Vedas — Ṛgveda, Śukla and Kṛṣṇa Yajurveda, Sāmaveda and Atharvaveda — across all four layers: **Saṃhitā**, **Brāhmaṇa**, **Āraṇyaka** and **Upaniṣad**. Saṃhitās can also be browsed by **ṛṣi**, **devatā** and **chandas** where an index exists; filters combine, so you can ask for every ṛk to Agni in Gāyatrī by Medhātithi Kāṇva. Text is shown in **Devanagari or Kannada** (with svara marks), with IAST, Padapāṭha and translation where the source has them.

It is a static site: plain HTML, CSS and JavaScript with pre-built JSON, no framework and no server.

## Run it locally

```sh
cd web
python3 -m http.server 8000
# open http://localhost:8000
```

## What's included

| Veda | Saṃhitā | Brāhmaṇa | Āraṇyaka | Upaniṣad |
|---|---|---|---|---|
| Ṛgveda | Śākala (tagged per ṛk) | Aitareya, Kauṣītaki | Aitareya, Śāṅkhāyana | Aitareya |
| Śukla Yajurveda | Vājasaneyi Mādhyandina | Śatapatha | Bṛhadāraṇyaka (under Upaniṣads) | Īśa, Bṛhadāraṇyaka |
| Kṛṣṇa Yajurveda | Taittirīya | Taittirīya | Taittirīya | Taittirīya, Kaṭha, Śvetāśvatara |
| Sāmaveda | Kauthuma (Sanskrit) and Griffith's translation | Pañcaviṃśa | Jaiminīya Upaniṣad Brāhmaṇa | Chāndogya, Kena |
| Atharvaveda | Śaunaka (tagged per sūkta) | Gopatha | none exists | Muṇḍaka, Māṇḍūkya, Praśna |

Details, licences and known gaps: [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md).

## Rebuild the data

The JSON in `web/data` is generated by `scripts/build-data.mjs` (Node 18+, no dependencies) from five public repositories. The per-text parsers live in `scripts/texts.mjs`.

```sh
git clone --depth 1 https://github.com/031323/vedaweb-data
git clone --depth 1 https://github.com/mahesh-ak/WSC2023
git clone --depth 1 https://github.com/bhavykhatri/DharmicData
git clone --depth 1 https://github.com/sanskrit/raw_etexts
git clone --depth 1 https://github.com/sanskrit/gretil-mirror

node scripts/build-data.mjs \
  --vedaweb vedaweb-data \
  --anukramani WSC2023/Anukramani \
  --dharmic DharmicData \
  --raw raw_etexts \
  --gretil gretil-mirror \
  --out web/data
```

## Tests

```sh
node scripts/test-lipi.mjs   # Devanagari → Kannada: word checks + every line of the data
```
