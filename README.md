# Vedāvalokanam (repository: VedaAlokana)

A web app for browsing the Vedas — Ṛgveda, Śukla and Kṛṣṇa Yajurveda, Sāmaveda and Atharvaveda — across all four layers: **Saṃhitā**, **Brāhmaṇa**, **Āraṇyaka** and **Upaniṣad**. Saṃhitās can also be browsed by **ṛṣi**, **devatā** and **chandas** where an index exists; filters combine, so you can ask for every ṛk to Agni in Gāyatrī by Medhātithi Kāṇva. Text is shown in **Devanagari or Kannada** (with svara marks), with IAST, Padapāṭha and translation where the source has them, and Sāyaṇa's bhāṣya for the Ṛgveda.

It is a static site: plain HTML, CSS and JavaScript with pre-built JSON, no framework and no server. It installs as an app and works offline (see below). Current version: **1.6.0** — see [CHANGELOG.md](CHANGELOG.md).

## Run it locally

```sh
cd web
python3 -m http.server 8000
# open http://localhost:8000
```

## Install and offline use

Served over https (for example GitHub Pages), the app can be installed from the browser ("Install app" / "Add to Home Screen"). A service worker (`web/sw.js`) then:

- stores the app shell — code, styles, all fonts and icons — on first visit, so the app always opens offline;
- keeps every text that has been read (`data/*.json`) and refreshes it in the background when online;
- lets Settings → Offline download a whole Veda, or the Sāyaṇa bhāṣya, ahead of time, using the file lists in `web/data/offline.json`.

Nothing else needs the network: the pañcāṅga is computed on the device and location comes from the device.

**Releasing a new version:** bump `version` (and `released`) in `web/version.js` and add an entry to `CHANGES` in `web/app.js` and to `CHANGELOG.md`. The version change makes installed copies fetch the new app shell on their next visit and offer a reload; stored texts are kept.

## Rebuild the data

The JSON in `web/data` is generated by `scripts/build-data.mjs` (Node 18+, no dependencies) from five public repositories. The per-text parsers live in `scripts/texts.mjs`.

```sh
git clone --depth 1 https://github.com/031323/vedaweb-data
git clone --depth 1 https://github.com/mahesh-ak/WSC2023
git clone --depth 1 https://github.com/bhavykhatri/DharmicData
git clone --depth 1 https://github.com/sanskrit/raw_etexts
git clone --depth 1 https://github.com/sanskrit/gretil-mirror

node scripts/build-data.mjs \
  --vedaweb vedaweb-data \
  --anukramani WSC2023/Anukramani \
  --dharmic DharmicData \
  --raw raw_etexts \
  --gretil gretil-mirror \
  --sayana sa.wikisource.org/rigveda/rigveda.vyview \
  --out web/data
# also writes web/data/offline.json (node scripts/offline-index.mjs does just that step)
# --sayana is optional: git clone -b gh-pages https://github.com/project-vyasa/sa.wikisource.org
```

## Fonts

`web/fonts/` holds the Sanskrit fonts — Noto Serif Devanagari, Noto Serif Kannada and Shobhika (IIT Bombay) — each in two builds: `*-Vedic.woff` with svara marks drawn about twice as thick, and `*-Std.woff` with the font's own strokes ("Standard" in Settings). In both, every anudātta is anchored at one depth under the line instead of hanging from each letter (which made the bars step up and down), going lower only under a letter that reaches deeper. There are also Latin/IAST subsets of IBM Plex Sans and Gentium Book Plus, so no font server is needed. All are built from a checkout of [google/fonts](https://github.com/google/fonts) and the [Shobhika release](https://github.com/Sandhi-IITBombay/Shobhika/releases):

```sh
python3 scripts/make-fonts.py path/to/google-fonts web/fonts --shobhika path/to/Shobhika-1.05 --audit /tmp/afonts   # needs fontTools
node scripts/audit-marks.mjs /tmp/afonts   # anudātta depth, clearance and line extents over all the data (Playwright)
```

## Ṛgveda pāṭhas

The Ṛgveda can be shown two ways (Settings, or the switch in the reader):

- **Dākṣiṇātya pāṭha** (default) — as South Indian (Karnataka) recitation books print it:
  - a svarita on a heavy syllable gets the double stroke ᳚ (dīrgha svarita);
  - a class nasal inside a word is written as anusvāra (इंद्र, क्षु॒मंतं᳚), while one at the end of a word keeps its letter (म॑घवञ्चि॒त्रम्);
  - where two pādas run together, the swallowed a gets an avagraha (दक्षि॑णेना॒ऽभि, वृ॒त्वाऽत्य॑तिष्ठत्);
  - a kampa is written with its vowel in brackets, then the rest of the syllable and the numeral: र॒प्स्व(अ॒)न्१॒॑तः.
- **Śṛṅgeri** — the text as published by VedaWeb (after Aufrecht): every svarita with one stroke ॑; a kampa as १/३ with anudātta and svarita.

The Dākṣiṇātya pāṭha is computed in the browser by `web/dakshinatya.js`; the rules are written out at the top of that file. Word boundaries come from aligning each ṛk with its padapāṭha, and pāda boundaries from the syllable count of the half-verse. The dīrgha-svarita rules were derived from, and are tested against, Dayananda Aithal's [Saswara Rigveda Samhita](https://github.com/daithal/saswara-rigveda), whose dīrgha svaritas were themselves added by program: on all 10,552 ṛks they agree on 99.99% of svarita marks. No text is copied from that site. The other rules were read off printed Gaṇapati, Hiraṇyagarbha, Puruṣa and Devī sūktas, which the test reproduces exactly.
